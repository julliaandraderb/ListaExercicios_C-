# Lista Level 1 - Fundamentos da Programação em C#

## Descrição

Esta pasta contém a resolução da Lista Level 1 da disciplina de Programação em C#.

## Objetivo

Praticar os conceitos básicos da linguagem C# por meio de exercícios envolvendo:

- Entrada e saída de dados
- Operações matemáticas
- Tabuada
- Cálculo de médias
- Conversão de temperaturas
- Cálculos de salários
- Porcentagem
- E outros exercícios de lógica.

- **Lista_Level_1.pdf** → Enunciado da atividade.
