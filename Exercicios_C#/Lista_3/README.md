# Lista Level 3 - Estruturas de Repetição em C#

## Descrição

Esta pasta contém a resolução da Lista Level 3 da disciplina de Programação em C#.

## Objetivo

Praticar estruturas de repetição (`for`, `while` e `do...while`) e estruturas de seleção (`switch`) por meio de exercícios envolvendo:

- Menus interativos
- Tabuada
- Números naturais
- Soma e média de números
- Fatorial
- Padrões com asteriscos e números
- Operações matemáticas
- E outros exercícios de lógica.

> **Observação:** Nos exercícios que utilizam `for`, também foi implementada uma versão utilizando `while` ou `do...while`, conforme solicitado na atividade.
