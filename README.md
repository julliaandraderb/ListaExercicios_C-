# Exercícios em C#

Repositório criado para armazenar as listas de exercícios desenvolvidas durante o curso de Desenvolvimento de Sistemas.

## Linguagem

- C#

## Objetivo

Praticar os conceitos fundamentais da linguagem C#, incluindo:

- Variáveis
- Operadores
- Estruturas de decisão
- Estruturas de repetição
- Métodos
- Vetores
- Matrizes
- Funções

## Listas

### ✔ Lista Level 1

Contém exercícios introdutórios sobre lógica de programação e fundamentos da linguagem C#.

### ✔ Lista Level 2

Contém exercícios envolvendo estruturas de decisão e repetição.

### ✔ Lista Level 3

Contém exercícios mais avançados utilizando funções, vetores e matrizes.
